# Таблица параметров материалов (Terrain Materials)

Данная таблица описывает параметры, которые используются в системе динамической деформации ландшафта. 
Все настройки хранятся в ассете `DefaultMaterials` (скрипт `MaterialProfileLibraryAsset.cs`).

## Подробное описание параметров

Все параметры делятся на две группы: **Визуальные (TerrainLayer)** и **Геометрические (Noise)**.

### Визуальные параметры
*   **Diffuse Texture**: Основная текстура (albedo).
*   **Normal Map Texture**: Карта нормалей для детализации.
*   **Tile Size**: Размер текстуры в метрах (чем больше, тем крупнее текстура).
*   **Smoothness**: Гладкость/блеск (0 - матовый, 1 - глянцевый).

### Геометрические параметры (шум)
*   **Noise Type**:
    *   `Perlin` — плавные волны.
    *   `Ridged` — рваные пики (идеально для камня).
    *   `Billow` — пузырчатые холмы.
*   **Amplitude**: Высота неровностей в метрах (насколько сильно поднимается/опускается террейн).
*   **Frequency**: Частота детализации. Больше значение = мельче и чаще неровности.
*   **Seed**: Уникальный сид узора.
*   **Octaves**: Количество слоев шума (больше = детальнее).
*   **Lacunarity / Gain**: Множители для каждой следующей октавы.
*   **Sharpness**: Острота пиков (используется только для Ridged).
