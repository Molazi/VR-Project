# Правила
1. Никогда не пушим напрямую в main
2. Каждая задача - своя ветка
3. Один логический шаг - один коммит
4. Перед началом работы обновляем main
5. После работы push -> Pull Request
6. После merge удаляем ветку
7. Не коммитим Library/, Temp/, Logs/ и прочий Unity-кэш
8. Не работаем одновременно над одной сценой без договорённости

*Если возникли какие-то вопросы или вы в чем-то не уверены, то лучше лишний раз написать мне*

## Готовые команды
```
git switch main
git pull
git switch -c feature/название вашей задачи
```
```
git status
git add <только необходимые измененные файлы>
git commit -m "..."
git push -u origin feature/название вашей задачи
```
